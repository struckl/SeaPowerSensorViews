## R.A.T.S. Sensor Views is out
New mod: three windows and two map layers that show which of your units sees which contact, and with which sensor. Display only, built on your sensors' track estimates:
- **Sensor board**: units x contacts, a letter per sensor, age of the fix
- **Radar scope** with blind arcs, radar horizon, strobes and a measuring cursor
- **Sonar display** with waterfall, layer and depth strip, echo plot
- **Map layers**: sensor lines and sensor coverage

**Where the data comes from** Display only, built on your sensors' track estimates.

**Game version** Run on 0.8.7, the globe beta build is untried. Needs Anchor Chain.
